# LAPAS: Loan Approval Prediction & Advisory System

Honours project, University of Johannesburg. Three connected pipelines:

1. **Loan approval prediction**: four classifiers (random forest, XGBoost, Gaussian naive Bayes, from-scratch logistic regression), with XGBoost as the current champion (ROC-AUC 0.978).
2. **RAG advisory reports**: per-applicant reports grounded in lending-policy and regulatory documents, generated by an LLM through the HuggingFace Inference API, with LIME feature attribution.
3. **Retrieval benchmark**: TF-IDF vs dense embeddings (`all-MiniLM-L6-v2` + ChromaDB).

## Quick start

Requires Python 3.10, PostgreSQL 14 and a `.env` with `DATABASE_URL` and an LLM key: `HF_API_TOKEN`, or `ANTHROPIC_API_KEY` to use Claude (see `.env.example`).

```bash
uv pip install -e .

# backend (FastAPI) and frontend (Streamlit), in two terminals
.venv/bin/python -m uvicorn backend.main:app --reload --port 8000
.venv/bin/python -m streamlit run frontend/Home.py
```

## Rebuilding from the raw data

```bash
.venv/bin/python -m database.feature_eng                    # data/raw -> data/processed
.venv/bin/python -m scripts.train_model --tune --tune-n-iter 30
.venv/bin/python -m scripts.tfidf_chroma                    # builds both retrieval stores + benchmark
.venv/bin/python -m scripts.populate_db                     # resets the DB, loads ~2,000 scored applicants
.venv/bin/python -m scripts.generate_paper_figures
```

See [CLAUDE.md](CLAUDE.md) for architecture details and the macOS Intel constraints.
